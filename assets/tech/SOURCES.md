## SQL database symbol

`sql.svg` is the exact, unmodified regular-weight database icon from Phosphor Icons, used as a generic database symbol for SQL. SQL has no single product logo.

- Upstream: https://raw.githubusercontent.com/phosphor-icons/core/main/assets/regular/database.svg
- Repository: https://github.com/phosphor-icons/core
- License: MIT, copyright 2023 Phosphor Icons. The existing retained notice is [../icons/LICENSE.txt](../icons/LICENSE.txt).
- SHA-256 of downloaded bytes: `da7d3598430cbe3b334c308c03ca41e8c4c7bbbfa7891e914d7aa8e87d847423`.

SVG path geometry, colors, and viewBox are unchanged.

## GDScript

`gdscript.svg` is the unmodified 32px document icon from the original Godot Engine repository, tag 4.4. It identifies the GDScript language separately from the Godot engine mark.

- Original SVG: https://raw.githubusercontent.com/godotengine/godot/4.4/misc/dist/document_icons/gdscript_small.svg
- Original license: https://raw.githubusercontent.com/godotengine/godot/4.4/LICENSE.txt
- License: MIT, Godot Engine contributors and original authors. Retained as [GODOT-LICENSE.txt](GODOT-LICENSE.txt).

The SVG bytes are unchanged and contain no external resources or font dependency.
